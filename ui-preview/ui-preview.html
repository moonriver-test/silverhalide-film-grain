这一版改了什么

  • 结构沿用方案 B：展开式胶片列表，按彩负 / 黑白 / 反转三组分段
  • 主色 #a82f24 取代 #ff3b12 —— 亮度 L* 由 63 降到 38
  • 白字对比度仍 6.8:1（AAA），对暖灰底 3.3:1 —— 仍能撑起强调色，但不抢画面
  • 暗盒换成写实 3D 渲染：黑塑料筒身、金属卷轴孔、右侧伸出的片头带齿孔
  • 四款用同一母本换色生成，机位 / 光照 / 片头完全一致
  • 每个暗盒放在统一「承台」上并加落地投影，避免像贴纸
  • 图像统一 saturate(.9) 轻压饱和，四款配色才落在同一色调里
  • 胶片卡不再堆乳剂术语，只留「彩色负片 · 细颗粒」这类可读信息
