这一版改了什么

  • 整体转深色主题：页面底取参考图那块牛仔布的蓝黑 #0f141b，面板用 PS 深色主题的中性灰 #232323
  • 胶片素材从写实渲染改为珐琅徽章：扁平高饱和色块 + 匀黑描边 + 右侧带齿孔的片头条 + 顶层树脂高光
  • 素材改为内联 SVG 参数化生成，不再是位图 —— 23 款共用同一套几何，只换色路与文字
  • 色路按「品牌 × 分组」分配，共 7 条：柯达彩负琥珀 / 富士彩负绿 / 柯达黑白炭黑 / 富士黑白冷灰蓝 / 依尔福黑白象牙 / 柯达反转红 / 富士反转紫蓝
  • 感光度数字按框宽自动收字号，三位数与一位数都不会溢出
  • 承台在深色下改为内凹更深的井（浅色主题是凸起的台面，方向相反）
  • 强调色只用在「当前状态」上：ISO 块 / 列表选中行 / 画幅选中 / 滑块 / 主按钮 —— 语义一致，不滥用

设计 token

  • 面板 #232323 · 卡片 #2c2c2c · 承台 #191919 · 分割线 #383838
  • 强调 #c1382a（按下 #96291f，暗底小字用 #e0705f）
  • 对白字对比度 5.4:1（AAA 大字号 / AA 正文），对面板底 2.9:1 —— 只用于大块面，不用于小字
  • 正文 #eeeeee · 次要 #9e9e9e · 极淡 #6e6e6e
  • 圆角：面板 26 / 卡片 18 / 承台 14 / 胶囊 999 · 字重只用 600 / 700 / 800，数字一律等宽
