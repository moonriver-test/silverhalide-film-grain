01摘要与核心结论

本报告回答两个问题：胶片颗粒是怎么产生的，以及它在图像上呈现出什么统计与感知特征。所有结论都指向同一个工程目的——为后续插件定义「什么样的颗粒才算对」。

先给结论。以下十条是本报告全部推理的落脚点，后文逐条给出依据。

  1. 颗粒不是噪声，是「成像物质本身」。胶片图像的每一个像素都是有限个不透明颗粒的局部平均。颗粒是信号载体，不是叠加在信号上的干扰层。这决定了它必须参与成像（改变灰阶的方式）而不是覆盖在成像之上。
  2. 颗粒的产生链路上有四个独立的随机源，缺一不可。光子到达的泊松性、晶体尺寸的多分散性、显影过程的团簇与感染显影、以及观察时放大率与人眼的分辨极限。任何只模拟其中一环的方案都会露出破绽。
  3. 颗粒强度的物理定律是 σD ∝ √D。由 Nutting 定律（密度 ∝ 单位面积颗粒数）与泊松波动（ΔN = √N）直接推出，再叠加 Selwyn 定律得到完整的尺度变换关系。这是插件的「强度标定」应当遵循的物理骨架。
  4. 颗粒的空间分布是「团簇」，不是独立点。布尔模型的天然聚簇效应 + 显影的感染显影现象，共同产生 5–20 个显影晶体聚成的团块。团簇是胶片颗粒最核心的视觉签名，也是它与白噪声最容易分辨的特征。
  5. 颗粒噪声是「低频平坦、高频带限」的低通型，不是带通。Selwyn 定律（σ·√a = 常数）本身就等价于「低频功率谱平坦」，因此频谱不可能在中频出现峰值：能量集中在 DC 附近，在约 1/(2d)～1/d（d 为颗粒直径）处开始快速衰减。数码噪声的功率谱同样平坦，但没有高频截止——这才是两者的真正分界。（原文写作「带通」，2026-10-03 勘误。）
  6. 颗粒的感知强度峰值在中间调，两端趋零。从布尔模型可严格导出：颗粒的覆盖波动方差正比于 p(1−p)（p 为局部覆盖率），在中间调最大、在纯黑与纯白处为零。这解释了「天空、皮肤、中灰背景最脏，死黑和死白干净」这一普遍经验。
  7. 彩色胶片的颗粒是三层九层叠加的结果，且蓝通道最粗。实测数据显示 Kodak VISION3 500T 高密度处的 RMS 颗粒度：蓝 ≈ 0.025、绿 ≈ 0.010、红 ≈ 0.009，蓝通道颗粒度约为红通道的 2.8 倍。所以最终正像中蓝通道颗粒最强、红通道最弱，绝不是「三通道等强度的彩色噪点」。
  8. 颗粒感随放大率急剧增长，且是观看条件的函数而非图像的固有属性。柯达 PGI 数据：同一 135 底片，4.4× 放大时 PGI = 28（刚过阈值），8.8× 时 50，17.8× 时 79。这是「图片在 100% 视图下看起来比缩略图脏得多」的量化解释，也意味着插件必须提供与输出分辨率解耦的颗粒尺度控制。
  9. 颗粒应该是画面里最锐利的元素。真实胶片的图像信息先于颗粒丢失（胶片 MTF 下降快于颗粒对比度下降）。这条推论反直觉但极其重要：「图像略微柔化 + 颗粒保持锐利」= 胶片感；「图像锐利 + 颗粒糊」= 滤镜感。
  10. 存在一个已被验证的物理随机几何模型可以直接作为算法骨架。Newson 等人的布尔模型给出了从图像灰度到颗粒密度场的闭式映射，以及保持平均灰度的构造方式，且天然分辨率无关。这是本插件最合理的理论基础。
范围说明

本报告只研究颗粒这一个因素。真实「胶片感」还包含色调曲线（S 形肩部）、色彩耦合、光晕（halation）、冲洗批次差异等，这些不在本报告范围内，但在插件路线图中应作为后续阶段独立处理。原因是：颗粒是唯一需要物理建模才能做对的因素，其余多数可以通过曲线/查表近似。

这个区分为什么对插件设计是决定性的

「颗粒度」是可以在代码里精确控制的量（噪声的方差、功率谱）；「颗粒性」才是用户眼睛看到并评价的东西。二者之间隔着一个人眼加权滤波器和一个放大率缩放。只优化 σ 而不管加权与缩放，结果就是「数值上对了，看起来不像」。本报告 §3.5–§3.6 专门处理这个断层。

2.2 核心认知：颗粒参与成像，而非叠加于成像

模拟颗粒最简单粗暴的做法是「生成一层噪声，用某种混合模式盖上去」。这个做法在原理上就已经错了，原因有三层：

① 颗粒构成图像

在微观尺度上，胶片图像是二值的：某点要么被颗粒覆盖（不透光），要么没有（透光）。我们看到的连续灰阶，是局部平均密度。所以颗粒量必须随该处应有的密度变化——亮的区域需要更多颗粒，暗的区域需要更少。这要求颗粒生成是由图像内容驱动的。

② 颗粒与内容是同一层

叠加式噪声永远浮在图像「上面」，因为它是独立生成的一层。而真实颗粒是与图像细节纠缠在同一平面（更准确地说，同一三维乳剂厚度）上的。这就是为什么叠加式颗粒在放大后总显得「贴上去的」。

③ 颗粒有物理尺寸，噪声没有

颗粒有以微米计的物理直径，因此它在不同输出分辨率下占据的像素数不同。一般的逐像素噪声叠加默认「一个像素=一个噪声单元」，导致同一张图缩放到不同尺寸时颗粒的相对粗细完全错误。

④ 颗粒影响可分辨细节

颗粒作为随机调制，会降低颗粒尺度附近的细节可分辨度（相当于一个空间频率相关的干扰源）。真实胶片的分辨率上限部分就是由颗粒尺寸决定的。纯叠加式方案没有这个副作用，因此在高频细节区域看起来「太干净」。

03形成机理：从光子到可见颗粒的六步链路

下面按时间顺序拆解。每一环节末尾标出它注入了什么随机性——这些随机性正是插件需要复现的对象。

3.1 环节一：乳剂制备——晶体尺寸分布是第一个自由度

胶片乳剂是卤化银微晶分散在明胶中的悬浮体系。制备工艺（成核-生长控制、双注法、pAg 控制）决定晶体的平均尺寸与尺寸分布宽度。

易混淆点

「晶体尺寸分布」不是泊松分布。泊松性描述的是空间位置与光子到达的随机性；晶体尺寸是制造工艺确定的分布，现代乳剂刻意做窄（单分散）以抑制团簇与不均匀。文献中把二者混为一谈的情况很多，本报告严格区分。

随机性注入 ①的伴侣——尺寸多分散性：晶体越大越敏感。同一曝光量下，大晶体的潜影形成概率显著高于小晶体。这意味着「哪些晶体被显影」的集合不仅取决于光子数，也取决于尺寸分布。这个机制会放大低照度下的颗粒波动。

3.2 环节二：曝光——Gurney–Mott 潜影理论

潜影形成机制由 Gurney 与 Mott 于 1938 年提出，至今仍是标准框架：

  1. 光子被卤化银晶体吸收，从价带激发一个电子到导带，同时产生一个正空穴（电子-空穴对）。
  2. 光电子在晶格中迁移，被浅电子陷阱（敏化中心）捕获。浅陷阱由硫敏化（形成硫化银位点）、金敏化、晶格缺陷（刃型位错）或痕量掺杂引入。
  3. 被捕获的电子还原邻近的间隙银离子 Ag⁺ → Ag⁰。银原子聚集形成小簇。
  4. 当银簇达到约 4 个原子时即成为有效的潜影中心（文献区间 3–50 原子）。到这一步，晶体变成「可显影」。
化学放大的增益 潜影中心：4 – 50 个银原子
显影后颗粒：可达 10⁹ 量级银原子
⇒ 放大倍数 ≈ 10⁹（这是摄影史上提升感光度的核心技术）

这个巨大的非线性放大正是「少量光子 → 全有或全无的颗粒」这一二值跃变的来源，也是颗粒统计呈泊松性的根源。

随机性注入 ②：光子到达服从泊松分布。某个微区内落到晶体的光子数是随机变量。曝光量越低，相对波动越大（信噪比 ∝ √N），所以欠曝是颗粒恶化的主因——这一点被实测数据强烈支持（见 §3.7）。

工程含义

曝光不足 → 颗粒度上升，不是线性的，而是在特性曲线趾部附近急剧上升。如果插件要模拟「推冲（push）」，其强度曲线必须是非线性的，且在暗部更陡。

3.3 环节三：显影——团簇在这里诞生

显影剂在潜影中心处催化还原整个晶体，生成丝状 / 带状（filamentary, ribbon-like）的金属银缠绕团块，单个显影颗粒团尺寸约 0.5 – 2 μm。未曝光的晶体在定影阶段被溶解洗去。

关键现象是团簇化（clumping），它有两个来源：

来源 A：三维重叠（光学团簇）

乳剂是三维的。乳剂层厚度方向上有多个晶体，视线穿过整层时，不同深度的银颗粒会在光学上重叠。两个颗粒不需要物理接触就已经是一个光学实体。这个机制决定了：团簇是必然的，不是工艺缺陷。

来源 B：感染显影（infectious development）

显影具有自催化性质：已显影的颗粒会通过释放的显影产物或局部化学环境，诱发相邻未曝光晶体也显影。后果是提高表观感光度，但同时增加灰雾、改变特性曲线，并使颗粒性恶化。这是颗粒团簇的化学成因。

此外，显影条件（温度、搅拌、药液浓度）会显著改变团簇程度。搅拌不均会带来比手工操作高出一截的团簇率——这意味着颗粒不仅是胶片型号的函数，也是冲洗的函数。这是颗粒「有机感」的来源之一。

随机性注入 ③：团簇化。多个显影晶体（文献给 5–20 个）聚成不规则团块。这是颗粒视觉特征中最重要的一条，因为它产生了「尺寸大于单个颗粒」的低频结构。

3.4 环节四：漂白定影与彩色胶片
——染料云替代金属银

彩色胶片用成色剂（coupler）成色：显影剂被氧化后（QDI）与成色剂偶合，生成青/品红/黄染料。染料在显影银周围向外扩散形成染料云（dye cloud）——这种扩散同时向所有方向进行，因此边界柔和、呈团块状，中文文献形容为「奶油状」「云状」。漂白定影后银被移除，只留下染料云构成图像。

黑白颗粒与彩色颗粒的形态差异（必须区分建模）

  • 黑白：显影银丝团，边界相对锐利、对比度高，形态不规则、有方向性。
  • 彩色：染料云，尺度更大（约 2–5 倍）、边界模糊、浓度梯度平缓。视觉上更「软」，更容易融入图像，造成的锐度损失也更明显。

结论：「黑白颗粒」与「彩色颗粒」不能共用同一组参数——彩色颗粒必须更大、更软。这是插件的胶片型号预设必须分黑白/彩色两大族的理由。

3.5 环节五与六：观察侧——放大率与人眼

到这里，客观的颗粒度已经确定。但从「客观颗粒度」到「主观颗粒性」还要经过两级低通滤波：

  1. 放大 / 扫描：把底片上的微米级结构投影或采样到输出介质上。放大率 m 越高，单位视角内包含的颗粒数越少，单颗粒所占视角越大 → 颗粒越明显。
  2. 人眼：人眼本身是一个有限分辨率的低通滤波器。中科院/影像学界长期使用的工程近似是：在 40 cm 标准观看距离下，人眼等效于一个宽度约 560 μm 的高斯加权孔径（投影到相纸/输出介质上）。

这两级滤波共同决定「哪些空间频率的颗粒波动最终能被感知」。§3.5 的加权积分公式正是把二者写进同一个数学表达。

这是本项目最容易被忽略的一环

绝大多数广告滤镜只处理「制作侧」（生成噪声），完全不处理「观察侧」（滤波与缩放）。所以它们在缩略图尺寸用看起来还行，一放大就原形毕露。插件的设计必须把观察侧纳入参数体系。

04空间统计与度量体系

上一节解释了颗粒怎么来的，这一节回答「颗粒有多强、有多大、在什么频率上」——即可测量的部分。

4.1 Nutting 定律与 √D 律（颗粒强度的物理骨架）

推导链条清晰且经典，从三个事实出发：

① Nutting 定律：密度与颗粒数成正比 光穿过乳剂层时的衰减：  dI = −a·(N/t)·I(z)·dz
积分得透射率：  T = I(t)/I(0) = exp(−aN)
又因 D = −log₁₀T = −0.434·lnT ⇒ 2.3·D = a·N
N = 单位面积平均颗粒数，a = 单颗粒平均吸收截面（含颗粒外的时间平均）
② 泊松波动：颗粒数的涨落 N ± ΔN = N ± √N   （曝光是光子和晶体的量子力学相互作用，近似泊松过程）
③ 合并：√D 律 ΔD = (a/2.3)·ΔN = (a/2.3)·√N  ∝  √D
⇒   σD ∝ √D   颗粒度随平均密度的平方根增长

直观解释：密度越高，绝对涨落 ΔN = √N 越大，但相对涨落 ΔN/N = 1/√N 越小。所以细颗粒乳剂（同一密度下 N 更大）的统计噪声更低。

4.2 Selwyn 定律（尺度变换）

Selwyn（1935）的观察：对不太小的测量孔径，RMS 颗粒度与孔径线度成反比。与 √D 律合并，得到工程上最常用的统一换算公式：

Selwyn 定律与颗粒度的尺度换算 σ(D)·√a ≈ 常数   a = 测量孔径面积
GSelwyn = σD·√(2a)   （部分文献写 σ√a，系数定义不统一，比较时须核对口径）

综合换算公式（√D 律 + Selwyn 律） σ = σ₁ · (d₁/d) · √(D/D₁)
已知在孔径 d₁、密度 D₁ 处测得 σ₁，可推算任意孔径 d、密度 D 处的 σ。
这条公式对插件的直接用途

它给出了「颗粒强度 × 颗粒尺度」的联合标定基准。插件中「颗粒强度」与「颗粒大小」两个滑块不应独立作用——按真实物理，增大颗粒半径会同时改变每个分辨单元内的颗粒数 N，进而按 √N 关系影响 σ。二者耦合，才是物理正确的。

Selwyn 定律的适用边界

当单颗粒面积接近或大于测量孔径时，G 不再恒定（分母上的「平均」失效）。另外，二维随机圆盘模型的理论分析表明：随密度升高，√D 律会系统性低估颗粒度，原因是圆盘相互重叠使密度不再单纯由「孔径内圆盘数」决定。实际乳剂中颗粒在厚度方向分布，该效应相对较小，但作为算法设计者应知道这个偏差方向——高密度端真实颗粒度比 √D 律预测的更高。

4.4 功率谱（Wiener 频谱 / NPS）：颗粒的频率指纹

RMS 颗粒度把所有空间频率压缩成一个数字，信息损失很大。更完整的描述是噪声功率谱密度（noise power spectrum, NPS，又称 Wiener 频谱），通过密度涨落轨迹的自相关函数的傅里叶变换求得。

NPS 与前面指标的关系：

σ²(D) = ∫ [E(f)/f]² · NPS(f,D) df  /  ( A · ∫[E(f)/f]² df )   E(f) = 人眼空间频率响应（等效高斯孔径）
g(D) = 10³ · σ(D)·√A ≈ 10³ · √( NPS(1 cycle/mm, D) )   颗粒度系数与 1 cycle/mm 处 NPS 的近似关系

注意第一式：颗粒度本身就是 NPS 经过人眼加权后的积分。这说明「什么频率的颗粒重要」这个问题的答案，取决于人眼。低频斑块（mottle）虽然积分贡献小，但视觉上极其刺眼——这解释了为什么只用 RMS 颗粒度评价是不够的。

4.5 从颗粒度到颗粒性：人眼加权与对数律

心理物理实验给出的关键结论：

颗粒性的心理物理标度 G ∝ log σ²   颗粒性正比于颗粒度平方的对数（类别判断法 / Thurstone 定律得出）

含义：颗粒性对颗粒度的响应是压缩的。σ 从 5 增到 10（翻倍，σ² 增 4 倍），颗粒性的增加量约等于 σ 从 10 增到 20。这正是为什么颗粒度看起来「差不多」的两种胶片，视觉差异可以很大——反之亦然。

工程可用的近似是：在不做心理实验的情况下，用「人眼加权的 NPS 积分」作为颗粒性的代理量。上文的人眼等效高斯孔径（560 μm @ 40 cm 观看距离）就是用于这个积分。

4.7 色调依赖：颗粒强度的纵向分布

这是颗粒视觉特征中最容易被做错的一条。先看事实：

事实 A：负片密度域——颗粒度随密度单调上升

图 2 已给出：VISION3 500T 的 σD 从 D≈0.8 处的 0.004–0.006 升到 D≈3.0 处的 0.009–0.025，全程单调上升。这就是 √D 律。在负片上，最密的地方（最亮的高光）颗粒度最高。

事实 B：打印 / 观看域——颗粒度峰值在中间调

对胶片类成像系统实测的「颗粒度–密度」曲线显示：颗粒度在 D ≈ 0.75 附近达到峰值，向两端衰减。这是柯达把「中间调颗粒度 g(0.75 OD)」作为标准比较基准的原因。

事实 C：布尔模型的理论结果——波动幅度 ∝ √(p(1−p))

在随机圆盘布尔模型中，颗粒覆盖率 p 的点态方差为 p(1−p)，在中间调（p = 0.5）取最大值，在 p → 0 与 p → 1 时趋于零。物理含义：死黑区域没有颗粒（没有晶体被曝光），死白区域颗粒密到连成一片、波动消失。

三种说法为什么不矛盾——以及真正的结论

「高光最脏」（事实 A）与「中间调最脏」（事实 B、C）描述的是链路的不同环节。事实 A 是负片的客观颗粒度；事实 B/C 是最终观看时的感知颗粒性。二者的转换包含两个环节：① 负片 → 正像的色调反转会改变各密度区间的局部斜率（gamma）；② 感知颗粒性还被人眼频率加权与掩蔽效应调制。

对本插件的结论：我们的输入是已经完成的数码正像，处于事实 B/C 的语境。因此应该采用「中间调最强、两端趋零」的色调响应曲线，而不是「亮度越高颗粒越强」。这是把胶片物理正确映射到数码图像的关键一步，也是本报告与常见广告文案分歧最大的一点。

柯达自己的技术资料也在反复强调：「任何胶片的颗粒性感知都高度依赖于画面内容、复杂度、色彩与密度。」——这句话本身就说明颗粒性不是单一数值，而是一个多维函数。插件必须把这些维度暴露为参数，而不是塞进一个「强度」滑块。

05视觉特征：颗粒在图像上到底长什么样

下面从七个维度描述颗粒的「长相」，每条都给出对插件设计的具体要求。

5.1 尺寸层级：从晶体到感知颗粒，跨度接近三个数量级

尺度换算示例（把微米翻译成像素） 35 mm 画幅宽 36 mm，4000 dpi 扫描 → 5669 px → 157.5 px/mm
10 μm 的颗粒簇 → 1.6 px；　　30 μm 的颗粒簇 → 4.7 px
经验参考：高质量扫描的 35 mm 胶片，可见颗粒簇通常表现为 2–5 像素尺度。这个量级可作为插件默认值的起点。

5.2 团簇性：最核心的视觉签名

颗粒不是均匀撒开的独立点，而是成团出现，团与团之间留有空隙。这个特征来自三个叠加的机制：

  1. 布尔模型的聚簇倾向：随机圆盘叠加时，两个圆盘偶然重叠的概率远高于均匀分布，产生的视觉印象是「clumping」，这是该模型的固有性质，也是它比白噪声更「有机」的根本原因。
  2. 感染显影：化学上的正反馈使相邻晶体一起显影。
  3. 乳剂三维厚度：视线穿过多个亚层，不同深度的颗粒被投影叠加。
判别测试

把图像局部放大 400%，问：颗粒之间有「空档」吗？团块尺寸是否明显大于单个颗粒？如果看到的是大小均匀、分布均匀的散点，那它就是白噪声，不是颗粒。

5.5 空间频率与锐度

  • 低通带限频谱（§4.4）：低频平坦、在颗粒尺度处截止。这要求插件的噪声生成必须做高频截止，而不是白噪声。
  • 颗粒是画面中最锐利的元素。真实胶片中，光学系统的 MTF 下降使图像细节先模糊，而颗粒作为「后产生的对比度调制」，其对比度下降得更慢。推论（非常重要）：
    • 「图像略柔 + 颗粒锐利」→ 胶片感 ✓
    • 「图像锐利 + 颗粒模糊」→ 滤镜感 ✗
  • 颗粒降低细节可分辨度。颗粒在对数尺度上作为随机调制叠加，会在颗粒尺度附近掩盖细节。这解释了为什么真实胶片即使 MTF 很高，观感上仍不「锐利干净」。
  • 低频斑块（mottle）。颗粒功率谱的低频尾巴虽然能量小，但视觉上非常刺眼（大面积不均匀）。这是 RMS 颗粒度无法反映的维度，也是「看起来脏」的常见来源。

5.6 时间维度（对视频/动图相关功能有意义）

胶片的每一帧都有**独立的**颗粒分布（因为每帧曝光独立）。因此运动画面中颗粒会「沸腾 / 蠕动」（boil / dancing grain）。这是胶片运动影像最有辨识度的特征之一。

插件即便只处理静态照片，也应提供「更换随机种子」的能力，以便在批量处理组图时获得独立颗粒（组照中每张颗粒位置相同是明显的破绽）。

5.7 观看条件决定论与掩蔽效应

观看条件决定颗粒感（§4.6）

  • 观看距离：14 英寸为标准；距离增倍 → 颗粒感显著下降
  • 介质：屏幕 100% 视图 ≈ 极端放大，颗粒感远强于打印

尺度可变性 物理尺寸固定，随放大率改变视觉粗细，分辨率无关 与像素网格绑定，缩放图像时噪声尺度随之改变
色调依赖 中间调最强，两端趋零（波动 ∝ √(p(1−p))） 阴影/暗部最重（信号弱、增益高），高光相对干净
色彩特征 三层独立但耦合，亮度为主、蓝通道最粗，色度柔和 亮度与色度分离，色度噪声在暗部呈现色斑，更刺眼
时间行为 每帧独立 → 颗粒沸腾（boil），被视为「生动」 相对固定（固定模式噪声），被视为「干扰」
与内容的关系 参与成像：颗粒本身就是图像载体，与细节共存于同一平面 叠加在成像结果上，浮于图像表面
感知评价 「画布的织纹」——被大脑接受为材质，增加真实感与质感 「图像的劣化」——被大脑判定为缺陷
心理学维度值得单独强调

不规则、有机的纹理与规则、网格对齐的纹理，在大脑中的处理路径不同。前者被当作材质（texture）接受，后者被当作瑕疵（degradation）拒绝。这是「为什么颗粒可以是一种审美，而噪声不行」的根本原因，也是为什么「看起来像颗粒」在商业上比「数值上正确」更重要。同时这也意味着：任何网格化、周期性、平铺可见的方案都会瞬间破功。

07已有建模方法综述与评析

梳理现有五类技术路线，评价其在本项目中的可用性。

6.1 方法一：扫描颗粒叠加（Film Grain Overlay, FGO）

做法：预先拍摄标准灰卡并冲洗，扫描得到真实颗粒素材，作为多层素材以叠加/柔光模式合成到数字图像上。

优点

  • 纹理 100% 真实，无需建模
  • 实时性好（视频流程中广泛使用）
  • 专业工具（如 LiveGrain）在好莱坞级制作中被采用

致命缺陷（用于本项目的理由）

  • 分辨率绑定：素材的颗粒尺度是固定的，图像缩放后完全错误
  • 不随色调变化：一层素材均匀覆盖全图，阴影与高光受到同样的「纱」
  • 会平铺循环：大面积平坦区域出现可见图案
  • 需要额外素材包，体积大

结论：不采用。但「按密度分层的多套素材」这一思路有借鉴价值：LiveGrain 的做法是按不同曝光拍摄灰卡得到多套素材，按亮度区间分别合成。这与 SMPTE RDD-5 的「强度区间」思想一致，可以作为我们参数体系的参考。

6.2 方法二：参数化噪声叠加

做法：生成高斯/均匀噪声，按强度混合。典型代表：Photoshop 的「添加杂色」与「胶片颗粒」滤镜、ffmpeg 的 noise 滤镜、大量在线工具。

  • Photoshop 胶片颗粒滤镜暴露三个参数：数量（Amount）、大小（Size）、粗糙度（Roughness）——分别对应强度、颗粒尺度、颗粒形态的聚簇程度。这基本是正确的参数骨架，值得沿用其命名逻辑。
  • ffmpeg 的 noise 滤镜工作在逐像素级，无法控制颗粒尺寸（工具文档自己承认这一点），只有单色/彩色开关。这是典型的「噪声不是颗粒」实现。

结论：作为交互参考，不作为算法基础。其最大缺陷是：噪声尺度绑定像素网格、频谱为白噪声、无团簇结构。

6.3 方法三：频率域模型（SMPTE RDD-5 / H.264 Film Grain Technology）

这是目前唯一有国际标准级别的比特精确规范的颗粒合成方案，出自 Thomson（后为 Dolby/InterDigital）在 H.264 高清 DVD 时代的工程实践。

  1. 「颗粒尺寸」在实现层面等价于「二维低通滤波器的截止频率」——这是把物理尺寸参数化最干净的方式。
  2. 按亮度分段建模是标准做法。不是一条连续曲线，而是若干强度区间各自的参数组。这种结构实现简单、查表高效。
  3. 块效应的处理被写进了规范（去块滤波）。说明「分块处理会产生可见接缝」是一个必须正面解决的问题，而非可以忽略的细节。

结论：采用其参数体系思想，但不采用其图案库方案。原因：RDD-5 的 169 种图案库是为视频编码的比特精确性服务的，对 Photoshop 插件而言，其分辨率绑定（8×8 块）与固定图案库是负担。但我们应当沿用「强度区间 + 截止频率 + 种子」这个三元参数结构。

6.4 方法四：自回归模型（AV1 Film Grain Synthesis）

做法：用自回归（AR）模型生成噪声，参数包括 lag（0–3）与二维 AR 系数、颗粒强度、缩放函数。相比频率滤波模型更紧凑，能更好地表达各向异性与相关性。AV1 中颗粒合成是规范性过程。

结论：作为备选算法。AR 模型在「相关性」这一点上比白噪声好得多，且计算量可控。但它的参数与物理量（颗粒半径、染料云尺寸）没有直接映射关系，调参依赖标定数据。

6.5 方法五：物理随机几何模型（Newson-Delon-Galerne 布尔模型）★

这是本报告推荐的算法骨架。它从「胶片颗粒的物理现实」出发，用随机几何建模，并且——这是关键——有闭式公式把图像灰度映射到颗粒密度场。

模型的三个组成 ① 布尔模型（Boolean model）
Z = ∪ᵢ 𝓑(xᵢ, rᵢ)   随机圆盘的并集
中心 {xᵢ}：强度为 λ 的泊松点过程（均匀分布）
半径 {rᵢ}：独立同分布，可为常数或对数正态分布（均值 μᵣ、方差 σᵣ²）

② 覆盖率公式
P(𝟙_Z(y) = 1) = 1 − exp(−λ·E[πr²])

③ 灰度保持的 λ 选取（核心公式）
λ(y) = ( 1 / E[πr²] ) · log( 1 / (1 − ũ(⌊y⌋)) )
ũ = 归一化到 [0,1) 的输入灰度。这个 λ 的选取保证模型的期望值等于输入灰度——即「颗粒重构图像」而非「颗粒叠加于图像」。
渲染：滤波布尔模型 ṽ(y) = φ ∗ 𝟙_Z (y) = ∫ φ(t)·𝟙_Z(y − t) dt
φ = 高斯核，模拟「放大 + 人眼」这一观察侧低通。这一步是产生「颗粒感」的关键——没有它，输出只是二值散点。

工程实现（蒙特卡洛）：ṽ(y) = (1/N)·Σₖ 𝟙_Z( (y − ξₖ)/s )， ξₖ ~ 𝒩(0, σ²I₂)
s = 缩放因子（分辨率无关性的来源）。N 增大时按大数定律收敛到真值。

为什么这个模型对本项目是「恰好合适」

  • 物理正确：建模对象正是银颗粒的随机几何，而非拟合出来的经验噪声。
  • 天然团簇：布尔模型的固有聚簇效应直接产出胶片特有的团块结构，无需外加规则。
  • 灰度保持有数学保证：λ 的选取来自覆盖率公式的反解，不会改变图像的整体明暗。
  • 色调依赖自动正确：由 ũ → λ 的映射与后续高斯滤波共同产生「中间调最强、两端趋零」的颗粒波动，不需要人为拼一条曲线。
  • 分辨率无关：颗粒半径以连续空间坐标定义，缩放因子 s 独立。可以在任意分辨率下渲染，甚至放大到能看见单个颗粒。
  • 可用参数少而语义清晰：μᵣ（颗粒平均半径）、σᵣ（半径离散度）、σ（观察侧滤波宽度）、s（缩放）。四个参数就能覆盖很宽的胶片风格空间。

工程性能问题及其解法

纯蒙特卡洛实现的计算量很大（原论文的 C 参考实现在典型工作负载下较慢；有报告称 GPU 实现相对 CPU 提速两个数量级，重实现报告称在特定配置下可达 160× 以上的加速）。对 Photoshop 插件而言需要注意：

关键解法：用二阶统计量替代蒙特卡洛

有专利文献指出：在特定条件下，可以基于物理模型推导出颗粒噪声的一阶与二阶统计量（期望、方差、协方差），直接用「信号相关的相关噪声」合成，而不必做逐点蒙特卡洛模拟。该文献给出的重要结论是：

  • 滤波后布尔模型的方差只依赖于：输入像素值 u、高斯滤波标准差 σ、颗粒半径分布 f_R(r)；
  • 滤波后布尔模型的相关性不依赖信号——这意味着可以先用固定的相关滤波器建模相关性，再按像素亮度调制幅度。

这两条结论把「物理模型」与「实时实现」之间的鸿沟填上了：用物理模型确定「幅度曲线」与「相关核」，用滤波合成实际噪声。这正是本项目算法架构的核心思路。

7.5 客观验证方法

五道验收测试

  1. 频谱测试：对输出图的平坦中灰区域计算 NPS，与理论低通谱形 exp(−4π²σ_g²f²) 比对（RMS 偏差 < 30%），并检查 −3dB 截止频率是否与设定的颗粒半径成反比。这是最硬的客观测试。
  2. 均值保持测试：在均匀灰阶块上运行不同强度，检查均值漂移与方差是否符合目标曲线。
  3. 尺度不变性测试：同一图在 1× 与 2× 分辨率下渲染，各自归一化到相同物理尺寸后比较颗粒统计量，应一致。
  4. 色调响应测试：在 0–100% 的灰阶阶梯上运行，测量各阶梯的输出方差，应呈现中间高两端趋零的曲线。
  5. 盲测：把插件输出与真实胶片扫描件混在一起，让有胶片经验的观察者判断。感知层面的最终判据只有人。

09结论、局限与后续工作

8.1 研究结论

  1. 颗粒是可以被物理建模的。它的统计来源清晰（光子泊松性 + 晶体尺寸分布 + 感染显影 + 观察侧滤波），并且存在已经过学术界与工业界双重验证的数学框架（布尔模型 + 灰度保持的 λ 反解）。本项目不需要发明新理论，只需要正确地应用既有理论。
  2. 颗粒与噪声的差异是结构性的，不是强度性的。五条硬差异：空间相关性（团簇）、功率谱形状（低通带限 vs 无截止的平坦）、尺度可变性（物理尺寸 vs 像素绑定）、色调依赖方向（中间调 vs 暗部）、色彩构成（耦合的三层 vs 分离的亮度色度）。任何一条做错，用户都能看出来。
  3. 「看起来对」的关键在观察侧，而不是制作侧。PGI 数据表明放大率的影响大于胶片型号差异。制作侧只负责生成正确的客观颗粒度；观察侧的低通与缩放才是感知颗粒性的决定环节。
  4. 把物理量正确映射到数码图像是最大的设计风险点。负片的「颗粒度随密度单调上升」与观看时的「中间调颗粒最强」是两个不同环节的事实，把它们混淆会得到一个「越亮越脏」的错误结果。

8.2 研究中未能解决或数据不足的部分

诚实说明
  • 团簇的精确统计分布数据不足。文献给出「5–20 个晶体成团」「染料云 1–10 μm」「可视颗粒簇 10–30 μm」这样的区间，但缺少可直接用作算法参数的、按胶片型号分类的团簇尺寸分布数据。这部分需要通过实测（见 8.3）来标定。
  • 公开的绝对颗粒度数据有限且一致性一般。柯达是少数公开数据的厂商，但其曲线图目视读取存在误差；不同资料给出的 VISION3 500T 数值范围差别明显。相对关系（通道之间、随曝光变化）可信度高，绝对标定需实测。
  • 数码照片与胶片的「密度」没有天然对应关系。胶片颗粒度是定义在光学密度上的；数码图像的「亮度」是显示量。二者的映射关系（是否需要模拟一条特性曲线）需要专门设计，本报告只能给出方向（§7.1 约束 12），不能给出唯一解。
  • 掩蔽效应的量化模型缺失。「颗粒可见度随内容不均匀」被普遍观察到，但缺少可直接用的量化模型。因此本报告建议此项只作为高级选项，不进入默认行为。
